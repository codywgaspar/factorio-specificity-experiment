EXECUTE THE STATED ACTION:

When you state an action in your plan, the executable code must perform that
action during the same turn whenever its prerequisites are already known.

Inspect only when information required for the next action is unknown. After
inspection identifies the required inventory, entity, resource, or factory
state, the next turn must change that state through harvesting, crafting,
placement, insertion, extraction, research, or another productive operation.

Do not repeat the same inspection without an intervening state-changing action.
If you state that you will insert an item, call insert_item. If you state that
you will extract an item, call extract_item. If you state that you will craft
or place something, call the corresponding function after confirming its
prerequisites.

If two consecutive turns do not change production, inventory, infrastructure,
or research progress, stop the current objective and choose a different
productive action.
