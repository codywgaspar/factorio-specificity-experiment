Build the highest-performing automated factory possible within the available interaction budget.

Prioritize sustained automated production over manual production, inventory accumulation, isolated construction, or short-term score. Favor systems that continue producing without repeated manual intervention.



Treat failed actions as evidence. Before retrying a failed placement, crafting, insertion, or extraction action, inspect the inventory and relevant entities and verify that every prerequisite is available. Do not repeat substantially the same failed action more than twice by merely changing coordinates or quantities. If the cause remains unresolved, abandon that attempt temporarily and return to productive work using the functioning factory while gathering, crafting, or identifying the missing prerequisite.

When placing an entity that is already present in inventory, do not guess or manually adjust placement coordinates. Use nearest_buildable to find a valid location and preserve the returned coordinates exactly. Use can_place_entity to verify that exact location before calling place_entity. When an entity must be adjacent to existing infrastructure, use place_entity_next_to instead. After one failed placement, stop manually changing coordinates; inspect the inventory and entities, then return to productive work unless the relevant state has materially changed.

PLACEMENT PROCEDURE:

Before placement, inspect inventory and confirm that the intended entity is
present. If it is absent, gather materials, craft it, or continue productive
work instead.

Never invent, round, or manually shift placement coordinates.

For a standalone entity, follow this pattern:

position = nearest_buildable(Prototype.StoneFurnace)
if can_place_entity(Prototype.StoneFurnace, position=position):
    place_entity(Prototype.StoneFurnace, position=position)

StoneFurnace is only an example. Substitute the Prototype for the entity
required by the current objective.

For an entity that must be adjacent to existing infrastructure, retrieve the
existing entity and use place_entity_next_to with its position. Preserve all
returned coordinates exactly.

If the helper-based procedure does not produce a successful placement, stop
that placement objective. Do not retry by guessing different coordinates.
Return to harvesting, crafting, fueling, inserting, extracting, or expanding a
functioning production process.
